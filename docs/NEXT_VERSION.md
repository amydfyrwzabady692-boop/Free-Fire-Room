# نسخه بعد

- تقویم کاستوم‌ها
- علاقه‌مندی و دنبال‌کردن برگزارکننده
- پیشنهاد بر اساس Region
- رتبه‌بندی عمومی برگزارکنندگان (علاوه بر Trust Score داخلی)
- نمایش برندگان قبلی
- مدرک پرداخت جایزه با بررسی مدیر
- کد تخفیف/اسپانسر بدون شرط‌بندی
- PWA پنل
- چندزبانه کامل (زیرساخت locale آماده است)
- تیکت پشتیبانی
- Funnel مشاهده → شرایط → ثبت‌نام
- تشخیص هم‌پوشانی زمانی کاستوم‌های یک برگزارکننده
- API عمومی محدود برای برگزارکننده تأییدشده
