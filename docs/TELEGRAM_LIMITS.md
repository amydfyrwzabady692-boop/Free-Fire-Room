# محدودیت‌های Telegram Bot API

مواردی که **عمداً جعل نشده‌اند**:

1. **فوروارد بنر به N دوست** قابل اثبات قطعی نیست. شرط دعوت با Deep Link اختصاصی (`ref_TOKEN`) است. فوروارد فقط به‌عنوان کار پیشنهادی در متن راهنما آمده است.
2. **جلوگیری از اسکرین‌شات یا بازنشر** تضمین API ندارد. رمز در پیام خصوصی، شخصی‌سازی‌شده، با دکمه نمایش کوتاه و نزدیک به شروع بازی ارسال می‌شود؛ وعده امنیت مطلق داده نمی‌شود.
3. **کانال خصوصی**: بررسی عضویت فقط اگر ربات ادمین باشد. Invite link در صورت دسترسی ساخته/ذخیره می‌شود.
4. **getChatMember** تنها روش معتبر عضویت است. اگر ربات ادمین نباشد کانال به‌عنوان شرط منتشر نمی‌شود.
5. **Rate limit** ارسال انبوه (~۲۰–۳۰ پیام/ثانیه در عمل محتاطانه). Broadcast صف و تأخیر دارد.
6. **Login Widget** نیاز به دامنه ثبت‌شده نزد BotFather دارد؛ جایگزین: OTP داخل ربات.

نزدیک‌ترین جایگزین قابل‌اعتماد برای هر محدودیت در کد پیاده شده است.
